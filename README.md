# EUR Risk Calculator

A simple Forex risk management calculator built with **HTML, CSS, and JavaScript**. This tool helps me calculate their risk amount and position size based on account balance, risk percentage, and stop-loss value.

## Features

- Calculate risk amount per trade
- Position size calculation
- Easy-to-use interface
- Responsive design
- Fast and lightweight

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created to help Forex traders manage risk effectively and make informed trading decisions.
